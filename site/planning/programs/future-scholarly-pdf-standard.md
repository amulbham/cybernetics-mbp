- Select one paper explicitly by stable entry/source identity and write only to an explicit candidate output root.
- Record source revision, source/asset hashes, tool versions, rendering settings and output hash.

- Refuse output destinations inside existing canonical/deployable PDF paths during candidate generation.
- Treat candidate generation and published artifact installation as separate operations.
- Install a published PDF only from an owner-approved exact artifact record; verify bytes before and after placement.
- Refuse missing/mismatched approved bytes rather than generating replacements.
- Drive Download, Highwire, JSON-LD MediaObject and validation from one truthful selected state without creating a second self-derived approval oracle.

- Keep the six current canonical path/hash records unchanged.
