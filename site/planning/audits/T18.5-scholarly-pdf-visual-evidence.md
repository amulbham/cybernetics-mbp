## 2. Choices

- **Reference order.** Invariants-style working-paper density and convention decide structure; navy and ochre appear only as quiet cues. The mathematics-paper PDF was not supplied, so no match to its pages is claimed.
- **Font.** Latin Modern Roman 10 (regular, italic, bold, bold italic), GUST Font License, from the GUST e-foundry zip, plus Latin Modern Math (same foundry and license) for Greek via a `unicode-range` face; provenance, SHA-256s, and the glyph analysis in `public/fonts/print/README.md`. Loaded from the repository by a URL relative to the stylesheet; every body-text font in the four PDFs is an embedded `LMRoman10-*` subset.
- **Scale.** Body 11pt, line 1.4, justified with automatic hyphenation (`hyphenate-limit-chars: 7 3 3`; 8–13% of lines end in a hyphen); title 19pt, centered with the subtitle, byline, and date as one axis; h2 13.5pt; tables 10pt with 9.5pt bold headers; references 10pt; author note 10pt; page furniture 9–10pt. Text column 5.9in (margins 1.3in).
- **Furniture.** Page number bottom centre on every page, including the first. A running head, `Bham` (small caps, left) and the article's own `<h1>` text (italic, right, taken with `string-set`), on body pages only; page 1 has none. No authored field, hardcoded title, DOM, or builder change.
- **Palette.** Page `#fff`; ink `#111`; links and labels navy `#1f3a5f`; one ochre `#8a6a1c` hairline under the title block. Pillar and alert tokens keep their Signal values because they carry meaning.
- **Primitives, alerts, key findings.** Card chrome removed. Each keeps its label (small caps) and a left rule; alert rules keep their severity colors. Tables are booktabs-style: heavy top and bottom rule, one header rule, hairline row dividers, rows kept whole (`break-inside: avoid`). The T18.4 `thead th { white-space: normal !important }` rule is unchanged.
- **Pagination.** Headings, and the first two paragraphs after an `h2` (the protocol papers' "Responds to" and "Subtitle" lines), keep with what follows; orphans and widows 2.

## 5. Fonts and glyphs

Embedded fonts, from the PDF font resources: `LMRoman10-Regular`, `-Italic`, `-Bold`, `-BoldItalic` on every page of every paper, plus `IBMPlexMono-Regular` (the site's code font, FAFSA only). Text layer and rendered glyphs inspected for italic and bold spans, `é á ö ä Ü è`, `— – ’ “ ” … · × − → ¹ ² ³`, and a long reference URL (Chisel p17, `arxiv.org/abs/…`, which breaks as before).

Refinement (the three characters Latin Modern Roman lacks), checked in the PDF font resources and at 3.2× close-ups:

| Character | Where | Result |
|---|---|---|
| `δ` U+03B4 | Invariants p6, Three SOS p5 | Embedded `LatinModernMath-Regular` (a `unicode-range: U+0370–03FF` face, same Computer Modern design). Was Times New Roman. |
| `∞` U+221E | FAFSA code block, p24 | Embedded `LMRoman10-Regular` via a `unicode-range: U+221E` face placed ahead of the mono face. Was Courier New. |
| `⚠` U+26A0 | Three SOS pp4–5 | **Unresolved: system `SegoeUIEmoji`, as before.** The source writes U+26A0 U+FE0F (an emoji-presentation sequence). In an isolated test, Chrome rendered the system color emoji in every case that included the selector: a bundled Noto Sans Symbols 2 face first in the stack, that face with the selectors in its range, and `font-variant-emoji: text`. Without the selector the bundled face did render a monochrome glyph, but the corpus has none. Removing the selector means editing manuscript text, which is excluded; the test font was not shipped. |

A color-emoji font bundled in the repository is untested, would be megabytes for two glyphs, and would still put a color glyph in a scholarly PDF. No other character in the four papers uses a non-Latin-Modern, non-Plex font.

## 6. Furniture and pagination checks

- Running head on 28 / 20 / 16 / 11 body pages, absent on page 1, one baseline, inside the text column; the head text equals each paper's `<h1>`; all four titles fit on one line. Page numbers equal the physical page on 29 / 21 / 17 / 12 pages.
- Page fill is 81–99% on every non-final page except FAFSA p27 (77%, before a table that keeps its rows whole) and the final pages. Final pages: FAFSA 59%, Chisel 55%, Invariants 39%, Three SOS 19% (the author note alone, because it keeps itself whole and just missed fitting on the previous page). No blank page, overlap, or clipping.
- Headings within the last three lines of a page are each followed by two lines of text (widow control); no heading or section opener is last on a page.

## 9. Accepted caveats and open decisions

1. `⚠` (Three SOS, two places) still renders from the system emoji font (section 5). Options: accept (it is a small colored warning mark beside a bold label, as before); or Product Authority approves editing the two source lines to drop the emoji selector (a manuscript change, outside this ticket).
2. Automatic hyphenation: a word split at a line end reads `prove‐` / `nance` in the text layer, as in any typeset paper; tables and references do not hyphenate. One declaration (`hyphens: auto`) turns it off.
3. Font loading relies on Vivliostyle resolving `--style` URLs against the stylesheet file (verified here; Vivliostyle also requires the stylesheet inside the project). The first staging CI build is the independent confirmation on Linux.
4. `public/fonts/print/` publishes the four font files and license under `/fonts/print/`; nothing links to them.
5. Three SOS ends on a page holding only the author note.
6. The mathematics-paper reference was not supplied; no comparison to its pages is claimed.
