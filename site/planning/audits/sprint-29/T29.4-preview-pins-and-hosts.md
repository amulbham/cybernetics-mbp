## 8. Anonymous denial and canary (specified, scripted, tested)

`T29.4-kit/anonymous-denial-check.mjs`, no cookies and no custom headers, on the alias and on every immutable URL. Paths: article GET and HEAD, PDF GET, HEAD and `Range: bytes=0-15`, root, explicit `index.html`, the article without a trailing slash, the article with a query string, `robots.txt`, `sitemap-index.xml`, one `/_astro/*` asset (and `/cdn-cgi/trace` as an informational record). **Only the first response is judged**; redirects are never followed implicitly. Pass **only** for a 301/302/303/307/308 to an `https` URL on the owner's Access team host (pinned from Phase 0 evidence as `--access-host`; the default `*.cloudflareaccess.com` suffix is a fallback) with path `/cdn-cgi/access/…`, no PDF content type, no `Content-Range`, no `%PDF-` bytes and no candidate marker (case-insensitive) in any body. A bare 401/403 is not attributable to Access and fails unless the owner allows it. **The login redirect is then validated separately**: one more request to the `Location` must be an Access login page (HTML 200, or a further redirect inside the Access host) with no artifact bytes. Any 200, 206, 304, 404 or other first status on a protected host fails. Production and live hosts (rows 3 and 5) must answer 404 and carry no artifact. Negative controls (§6) must be judged EXPOSED first, and the PDF control must return real PDF bytes. `server` and `cf-ray` are recorded on every request. `test-kit.mjs` (65 cases) covers each of these, including a host that protects only the article path, a suffix-bypass login host and a login destination serving PDF bytes.
Canary: two harmless deployments (no manuscript content; `--canary` rejects any pinned Paper C hash or manuscript phrase) under the final label, reviewed by the named independent verifier before upload; the second proves a **new** immutable URL is protected at birth; the first is then deleted. A root page with a `mailto:` link shows whether the host rewrites HTML. The authenticated kit, including the alias cookie, is exercised end to end on the canary.
