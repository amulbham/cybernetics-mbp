5. **Network.** If the Executor cannot reach `cybernetics-mbp-preview.pages.dev`, `*.cybernetics-mbp-preview.pages.dev` or `<team>.cloudflareaccess.com`, approve each exact host in the session prompt when asked.
6. **The production hostname.** After creation the Executor requests `https://cybernetics-mbp-preview.pages.dev/` article and PDF paths and expects 404. If it returns anything else (for example an error page or a redirect), stop and report; the check is not weakened.

In the developer-tools Console run this and save the clipboard as `page-metrics-desktop.json` (window 1440 px wide, device toolbar off or 1440×900 emulation) and, after switching to a 390×844 phone emulation, as `page-metrics-mobile.json` (`Get-Clipboard | Set-Content -Encoding utf8 page-metrics-desktop.json`; the kit also accepts UTF-8 with BOM and UTF-16):
   `(async()=>{const b=await (await fetch(location.href,{cache:'no-store'})).arrayBuffer();const h=[...new Uint8Array(await crypto.subtle.digest('SHA-256',b))].map(x=>x.toString(16).padStart(2,'0')).join('');copy(JSON.stringify({url:location.href,innerWidth,innerHeight,scrollHeight:document.documentElement.scrollHeight,devicePixelRatio,routeHtmlSha256:h,userAgent:navigator.userAgent}))})()`

A single full-page capture is acceptable where the tool can produce it; no image may exceed 16,384 px in height.

## Containment and teardown

On any exposure or mismatch, the fastest containment is to **delete the whole project** (this removes every hostname at once; run `npx wrangler@4.129.0 pages project delete cybernetics-mbp-preview` and confirm in the dashboard), then verify that every hostname is gone and send the evidence. The slower alternative (upload a neutral deployment to the same label, then delete the candidate deployment with `--force`) leaves the old hash URL reachable meanwhile and is only for a contained, non-exposure issue. After your visual decision, unless you keep the preview, delete the project, run `wrangler logout` or revoke the token, and let the Executor verify the anonymous results one last time.

## Stop at any of these

A mismatch from `verify-upload-dir.mjs` or a kit-digest mismatch; a project subdomain other than `cybernetics-mbp-preview`; any anonymous first response that is not an Access redirect (a bare 401/403 is not accepted unless you explicitly allow it); a failed login-redirect validation; a control that is not judged exposed; a production or live host that serves the route or PDF, or a production host that does not 404; a deployment in `deployment list` that is not accounted for; an invalid session; a changed hash; a Wrangler notice about Functions or `_worker.js`; an Access application with a path restriction, bypass or service-auth policy.
