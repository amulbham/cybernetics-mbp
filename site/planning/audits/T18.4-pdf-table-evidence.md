## 2. Experiment

One attempt was needed. Rule tried: `thead th { white-space: normal !important; }` only. `overflow` on the wrapper and every other property were left alone; a wrapper-overflow override was not needed and was not tested. Result: all 19 tables complete in the text check and in rendered pages, no overlapping text boxes, page counts unchanged (55 / 38 / 31 / 22). The cause at rule level remains inferred (nowrap headers widen the table past the print column while the wrapper clips); the fix confirms headers are the driver for these four tables, not that nothing else could ever clip. A future unbreakable body string wider than its column could still clip.

## 3. Temporary completeness check (uncommitted; scratchpad only)

Compares every cell of each paper table (from the built HTML) with the PDF text on the table's pages. Pages are found by ordered anchors (header first words, first row), so they survive reflow. A cell fails if any word of 3+ letters is absent, or its last three words are not contiguous. It detected all four baseline losses and passed the fixed corpus (`wordsMissing=0 tailMissing=0` for all 19).

Risks seen or expected: a split row's last lines fall outside the located range (F11 baseline, false positive; fixed by a one-page extension, which can itself mask a missing word that recurs on the next page, as it did for C01's header word "authorship"); repeated words elsewhere on the same pages (false negative); apostrophes emitted as separate items (handled by stripping); hyphenation; casing and CSS-transformed header text (lowercased); mislocation when a table's start anchors recur (S02's first attempt matched prose). It does not prove visual correctness; rendered pages were viewed for every table page that changed. No permanent validator was added.

## 5. Corpus review results

- No information loss: 19 of 19 complete in text and in rendered pages. No overlapping text boxes anywhere. Items past the column edge: none on table pages; the single remaining item is the label "WITH COMPILER" on FAFSA p47, a full string, present before and after, unrelated to tables.
- Legibility: table body 10.5pt, header labels 9pt, unchanged; the wrapped headers stay readable. Narrow 5-column tables (F01, F08) produce tall rows; legible.
- Continuation: header repeated on every continuation page; split rows now F11 row 1, I01 row 4, S02 row 7 (baseline: F10 row 5, F11 row 7, I01 row 4, S02 row 6). Existing pagination observations are not defects here and were not worked on.
- Page counts unchanged (55 / 38 / 31 / 22). Reflow cascaded through FAFSA p18 onward, Chisel pp5–7 and 26–28, Invariants pp17–18, Three SOS pp3–4 and 17–22.

## 7. Conclusion

The repeated PDF table information-loss defect is fixed by one general print-only rule. All 19 paper tables are complete and legible after reflow; screen behavior is unchanged. The text-completeness check remains a candidate automation only; promoting it needs separate evidence and authorization.
