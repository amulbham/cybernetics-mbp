# T18.0 — Publication artifact and rendering evidence

Audit only. No route, PDF, or content was changed. Production PDFs were downloaded from `amulbham.com` on 2026-09-25. They were rebuilt by the docs-only deploy of `8e60f6b` (PDF creation timestamps that day).

## A. PDF pipeline and identity

Corpus reconfirmed: four `format: paper` entries, one essay, one published IWL. No memos.

`canonicalPath()` is `/research/{category}/{entry.id}/`. A paper's category is its `pillar`. The slug is `entry.id`, the content directory name. It is not a second title slug.

`ResearchLayout.astro` builds `canonicalURL` as that same path, then `paperPdfUrl = new URL('paper.pdf', canonicalURL)` for papers only. Three readers use that one value: Highwire `citation_pdf_url`, JSON-LD `MediaObject.contentUrl`, and the Download link (`<a href>` with no `download` attribute, so a saved file takes the URL's last segment). `scripts/build-research-pdfs.mjs` writes `dist{route}paper.pdf`. `scripts/validate-research-pdfs.mjs` requires that filename, equates the three consumers to `{canonical}paper.pdf`, and fails if an essay or other non-paper has a `paper.pdf`.

Owners that must move together for `{entry.id}.pdf`: the `paper.pdf` literal in `ResearchLayout.astro`, the builder output path, and the validator's expected path and URL. Documentation that states `paper.pdf` as the contract (`PUBLISHING.md`, `AGENTS.md`, `CONTENT-MODULES.md`) would follow an implementation ticket, not this audit.

Deployed checks, HEAD or GET:

| URL | Result |
|---|---|
| Each paper's `paper.pdf` | 200, real PDF bytes |
| `.../the-chisel-fallacy-what-pangram-actually-measures/the-chisel-fallacy-what-pangram-actually-measures.pdf` | 404 |
| Essay `paper.pdf` | 404 |
| IWL `paper.pdf` | 404 |

The repo has no `_redirects` file and no redirect config. A 301 is not a current behavior. Static hosting will serve whatever file the build emits. Compatibility choices, none selected:

- Emit only `{entry.id}.pdf` and point `paperPdfUrl` at it. One URL. Existing `paper.pdf` links 404.
- Also keep emitting `paper.pdf`. Old links work. Two URLs, which breaks the one-authoritative-URL rule unless one of them is not public.
- Add a new redirect artifact from `paper.pdf` to the slug file. Possible only as new configuration. Not available today.

The target file sits beside `index.html` because `canonicalURL` ends in a slash. Example: `/research/ai-systems/the-chisel-fallacy-what-pangram-actually-measures/the-chisel-fallacy-what-pangram-actually-measures.pdf`.

## C. Live tables

Separator rows in source: FAFSA 12, Chisel article 3, Invariants 2, Three SOS 2, IWL 14. The essay has none and is excluded. No other long-form research page has a table.

Screen rule, shipped today: every table is wrapped in `.table-container` with `overflow-x: auto` and `tabindex="0"`. `thead th` is `white-space: nowrap`. A 390px capture of the Chisel and FAFSA article tops shows prose, the title, and the masthead wrapping inside the column. The tables sit below that capture. Wide header rows (FAFSA's five-column protocol table, twice; Three SOS's four-column matrix; IWL ledger and decision tables) are the overflow cases. Short-header two-column tables can fit and still take a tab stop. That is the non-overflow focus finding: the wrapper is focusable whether or not it scrolls.

Print CSS does not override `nowrap` and does not define repeating table headers. PDF table fragmentation is therefore a manual check, not something this audit measured page by page.

Author intent is not required to see that nowrap headers plus a scroll container are the current screen mechanism. It would be required to decide a different mobile layout, such as stacking rows.

## D. Repeated versus isolated

Repeated print defect: the ORCID line break, all four PDFs.
