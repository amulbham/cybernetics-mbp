# T18.2 — Long-form reading baseline (HTML)

Measurement only. No screen typography, layout, or font change was made or is authorized. Input for a later Reader-PR phase; heuristic ranges below are references, not pass/fail constants.

## Fixture and method

**Article:** `the-invariants-of-self-organizing-systems` (paper, 31 PDF pages, 10 `##` sections, 32 references). Chosen because it is prose-dominant, has the full normal shell (title, subtitle, masthead, DOI, TOC, references, AuthorNote) and no exceptional layout. Not chosen: Chisel (IWL link), FAFSA (tables, warning primitives, 12 tables).

**Method:** built site (`npm run build`) served by `astro preview` on `127.0.0.1`; Browser-pane viewport emulation at 1440px and 390px, page reloaded after each resize; `document.fonts.ready` awaited before every computed-style read (Atkinson 400/700 and IBM Plex Mono 400 confirmed `loaded`; the Arial/Courier fallback faces were not the rendered faces). Measure = paragraph box width; "ch" figures use the rendered width of `0` at the paragraph's own font; "chars/line" = paragraph characters ÷ rendered line count. Representative paragraph = first direct `.prose > p` over 250 characters.

**Shell and chrome.** Desktop: `.article-body` is a flex row; prose starts at x=193, sticky TOC rail (220px) at x=1013; header 80px; 2px fixed `ScrollProgress`; no horizontal overflow. Mobile: rail `display:none`, sticky `<details>` "On this page — 9 sections" (52px tall, closed by default) above the text; header 67px; `ScrollProgress` present; no horizontal overflow; no child of the prose column wider than the column at load. **Canonical breakpoint (additional observation):** `@media (min-width: 1100px)` swaps the mobile TOC bar for the rail; verified at 1099 (mobile TOC) and 1100 (rail). Prose stays 720px at both, so the swap changes peripheral chrome, not the reading column.

**JavaScript dependence of core reading.** In the raw served HTML (no script executed) the abstract paragraph, all 11 `h2`s, 32 reference entries (`id="ref-N"`) and 12 TOC links are present; there is no `<noscript>` block. Eight `<script>` tags exist. JS supplies theme toggle and persistence, TOC scroll-spy, scroll progress, and `ClientRouter` navigation. Reading the article does not depend on JS; without it the theme falls back to `prefers-color-scheme`.

| DESIGN CHOICE | Atkinson + IBM Plex Mono pairing; warm off-white and near-black palette; 1.25-ratio type scale; headings not stepping down on mobile (h1 48.8px in a 318px column); heading gap above equal to paragraph gap; primitive and masthead styling |

## Future Reader-PR observations (not blockers, not authorized changes)

- Heading scale does not step down at 390px; h1 and h2 are large relative to a 318px column.
- Space above a section heading equals the paragraph gap (30px / 27px), so section starts carry no extra separation.
- Mobile text column is 81.5% of the viewport, with 18px padding each side.
- The chosen measure metric (`0`-width ch versus actual characters) changes whether desktop is under or over 60–70.
