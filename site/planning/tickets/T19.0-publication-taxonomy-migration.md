## Goal

Replace `pillar` with a required, centrally defined `category` as the sole routing input; separate editorial category from scholarly-PDF eligibility; migrate the five live entries; and make every retired public URL a direct 301 while all four scholarly PDFs survive.

## Why now

Product Authority approved a four-destination taxonomy (2026-10-13). Routes derive from `pillar` today, so this is a route migration, not a label edit. It must land before the Desk manuscript pilot, whose category and DOI depend on it.

## Scope

1. **Registry** (`categories.ts`, replaces `pillars.ts`): ordered `CATEGORIES` = `{slug, label, description}` for the four; the zod enum, nav lists, labels and descriptions derive from it. `memos` is a reserved route-only entry (label and description for its empty page), not a `category` value, not in navigation. Descriptions for `cybernetics`, `ai-systems`, `essays` carry over unchanged; `knowledge-work` uses decision 15.
2. **Schema**: `category` required (enum); a present `pillar` key fails the build; `doi` requires `format: paper`; the "paper requires pillar" refine is removed.
3. **Routing**: `categorySegment(entry)` returns `entry.data.category`. One exported helper builds a routing entry from raw frontmatter and throws on a missing or unknown category; the three pseudo-entry sites use it. `research-routing.ts` gains `ogImagePath(entry)`; `ResearchLayout.astro` and the OG route use the routing helpers for canonical URL, OG path and breadcrumbs (no inline `/research/${…}` templates).
4. **Route history** (`route-history.ts`, the one new source of truth, authorized here). One row per entry publicly served on production: `{id, categories, pdf, iwl}`.
   - `categories`: append-only; every category segment under which the entry has been, or by this ticket will be, publicly addressable.
   - `pdf`: a public scholarly PDF at `{id}.pdf` (and the legacy `paper.pdf` URL) has been promised.
   - `iwl`: a public companion IWL route has been promised.
   - The rows hold no current category, format or IWL state. A retired-category map (`policy-systems` → `/research/essays/`, `seo-architecture` and `systems-architecture` → `/research/`) lives beside them.
   - Seed (ids are `src/content/research/` folder names):

5. **Redirects**: one generator, used by `build-research-pdfs.mjs` to write `dist/_redirects` and by `validate-research-pdfs.mjs` to compute the expected set. Input: route-history rows, current entries (frontmatter), routing helpers. Output: explicit single-hop 301 lines, no splats, no chains.

## Implementation contract

- **Source of truth**: `category` (frontmatter) → `categorySegment()`; everything else derives. `format` alone decides PDF/Highwire/`ScholarlyArticle`/`isPartOf` (logic and call sites unchanged).
- **Fail closed**: a missing or unknown category, a retained `pillar`, `doi` on a non-paper, or a route-history violation fails the build or validator; no `undefined` route is ever emitted.
- **Route-history validation** (`validate:pdfs`, against generated artifacts):
  1. Every row's entry exists.
  2. The entry's current category (from frontmatter, via the shared helper) is in `row.categories`, so a published entry cannot move without an explicit append.
  3. `row.pdf` ⇒ the entry is `format: paper` and `dist` holds `{currentRoute}{id}.pdf`.
  4. `row.iwl` ⇒ the `iwl` collection holds a published IWL whose parent is the entry and `dist` holds the current `iwlPath()` page.
  5. Every generated redirect target exists in `dist`.
  6. No file exists at any non-current historical route or retired-category route (a retired path must be a redirect, never a shadow).
- **Redirect coverage**: for every row and every category in `row.categories` other than the entry's current one, the generator emits lines for the Article (with and without trailing slash), the IWL if `row.iwl` (both slash forms), `{id}.pdf` and legacy `paper.pdf` if `row.pdf`, and the OG image. For `row.pdf` entries, legacy `paper.pdf` at the current route is also emitted. Each retired category emits both slash forms. All lines target the final current URL in one hop. The old `paper.pdf` lines for Chisel and FAFSA are replaced, not chained.
- **Matrix handling**: the matrix below is the drafting-time expectation, derived from `e5b3dbb` and production on 2026-10-13. The Executor verifies each source against the baseline (Q3). A source proven never public is flagged and removed; a public URL the matrix missed is added. The Executor may not narrow coverage otherwise. The final set is recorded in the evidence file. A discrepancy that changes a public-route decision stops the work.
- **Compatibility**: new-route `paper.pdf` never existed, so no line. The sitemap lists new routes only.
- **Rollback**: a revert commit on the deploying branch; Actions rebuilds the previous route set and `_redirects`.

11. A nav/footer category link to an unbuilt page → link-resolution error.
