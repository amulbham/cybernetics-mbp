## Problem
Current `site/scripts/carry-over-pdfs.sh carry` checks six PDF bytes **against whatever `PDF_MANIFEST` Actions passes**; it does not independently validate that variable against the authorized six-row baseline. A local preflight is bypassable by later `main` pushes and `workflow_dispatch`. The independent check must execute *in the deployment job that actually uploads production*.

## Allowed minimal source delta
1. **Independent pinned baseline:** add `site/scripts/fixtures/approved-six-production-pdfs.sha256` containing exactly the six owner-approved unique path/hash pairs from T28.0, reviewed byte-for-byte independently. **Never derive it from active `PDF_MANIFEST`, current `dist` or `expected.txt`** (only two special release-expectation rows). Any future baseline modification is a separate version-custody authorization.
2. **Checker:** add `site/scripts/guard-production-six-pdfs.mjs` (or comparably bounded shell). Strictly parse the *effective runtime* `PDF_MANIFEST` from Actions environment and independent six-row file; reject missing/extra/duplicate/malformed paths, invalid hashes, any non-approved substitutions, disabled `PDF_CARRY_OVER`, unauthorized `PDF_RELEASE=new-version`, and any bypass switch. Compare complete sets even if reordered.
3. **Actual deployable bytes:** after production carry, enumerate `site/dist/` and require **exactly six PDF paths**, no symlinks/extras/missing files, each valid PDF and SHA-256 matching the pinned baseline. Checker exits nonzero before upload on any discrepancy.
4. **Mandatory workflow wiring:** change only `.github/workflows/deploy-pages.yml` to run guard **after main carry and before `npm run deploy:pages`** in the same job. Supply runtime `PDF_MANIFEST: ${{ vars.PDF_MANIFEST }}`, `PDF_CARRY_OVER: ${{ vars.PDF_CARRY_OVER }}`, `PDF_RELEASE: ${{ vars.PDF_RELEASE }}` via env, not a scratch fixture. The step must run without `continue-on-error` for **both production triggers: `main` push and `workflow_dispatch` on `main`**; no branch bypass, artifact upload shortcut or skip flag. Preserve existing carry-over and staging isolation. Inspect all other live production upload entrypoints; stop if more paths require scope.
5. **Synthetic executable tests:** tests for owner-six PASS, wrong/extra/missing/duplicated manifest line, alternate hash, `PDF_RELEASE` bypass, carry-off, missing/extra/symlink/altered dist PDF, guard removed/disabled in workflow, and push-vs-dispatch gate. Tests verify workflow *wiring*, not checker behavior alone, with disposable fixtures and no alteration of published PDFs or repo variables.
