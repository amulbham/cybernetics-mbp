## Problem
Current `site/scripts/carry-over-pdfs.sh carry` checks six PDF bytes **against whatever `PDF_MANIFEST` Actions passes**; it does not independently validate that variable against the authorized six-row baseline. A local preflight is bypassable by later `main` pushes and `workflow_dispatch`. The independent check must execute *in the deployment job that actually uploads production*.
