## Goal
Make CC BY 4.0 the default for new publications without altering historical licenses or frozen artifacts.

## Why now
T30.7 exposed a mismatch between the approved manuscript license and rendered article license. Resolve before the Sprint 30 batch release.

## Starting state
- Executor reports The Latency Trap renders CC BY-NC 4.0 despite its pinned source specifying CC BY 4.0.
- Owner reports Paper C uses CC BY 4.0 and site default remains CC BY-NC. Confirm actual code and production baseline before edits.
- Seven published PDFs and their integrity manifest are protected. T30.7 staging delivery must be verified before execution.

## Decisions already frozen
Owner approved forward-only CC BY 4.0; The Latency Trap is unpublished to production and must use its approved source license. No retroactive relicensing, PDF replacement or Zenodo changes. Preserve T30.7 editorial decisions.

## Questions this ticket may answer
Where is effective license determined, which legacy entries need explicit overrides, and which render/metadata/print consumers need alignment?

## Scope
- Inventory production work licenses and compare staging schema, defaults, overrides and output consumers.
- Change the forward default using the existing mechanism wherever possible; explicitly preserve legacy assignments where needed.
- Correct The Latency Trap license; align relevant visible notices, license links and machine-readable metadata.
- Ensure future PDF generation respects effective work license; distinguish site-wide notices from per-work terms.
- Document forward licensing and both manuscript intake paths.

## Explicit exclusions
No scholarly prose edits, new content framework, historical relicensing, published PDF regeneration/replacement, manifest edits, DOI/Zenodo changes, routing or indexing changes.

## Implementation contract
- A new entry without an override resolves to CC BY 4.0; supported explicit overrides take precedence.
- Each previously published work retains its pre-change effective license. Paper C remains CC BY 4.0.
- License label, URL, structured metadata where emitted, and future print projection agree with the effective per-work license.
- Preserve historical discrepancies as findings; stop if resolving one requires an owner decision. Do not infer license from a blanket footer alone.
- Reuse existing schema/validation mechanisms; unsupported or contradictory license inputs must not silently become a different license.

## Acceptance criteria
1. Pre/post inventory establishes unchanged licenses for all previously published works.
2. The Latency Trap displays CC BY 4.0 with matching link and applicable structured metadata.
3. New default and explicit override behavior pass targeted checks, including forward print projection.
4. Full build/validator chain passes; no unrelated content or route changes.
5. All seven frozen PDF hashes and manifest remain unchanged.
6. Canonical guidance updated; hosted staging verified after separate owner approval.
