## Goal

Give each paper one physical PDF at `/research/{category}/{entry.id}/{entry.id}.pdf`, and make `/research/{category}/{entry.id}/paper.pdf` a 301 to that file. Do not change the Article HTML URL.

## Why now

T18.0 mapped the identity chain and showed `paper.pdf` is the only emitted name, the slug URL 404s, and the repo has no redirect. Amul chose the 301 and forbade a second physical PDF.

## Starting state

`canonicalPath()` is `/research/{categorySegment}/{entry.id}/`. `paperPdfUrl` is `new URL('paper.pdf', canonicalURL)`. The builder writes `paper.pdf`. The validator requires that name and equates Highwire, JSON-LD `contentUrl`, and the Download href to it. Essays and IWLs have no PDF. Visual PDF and table findings from T18.0 stay open.

## Decisions already frozen

Filename is `{entry.id}.pdf` beside the article HTML. The slug is `entry.id`, not a title slug. Legacy `paper.pdf` is a permanent 301, not a second file. Article canonical HTML URL stays. One authoritative PDF URL. Indexing stays closed.

## Questions this ticket may answer

- Does the generated `_redirects` file survive until deploy and produce an unfollowed 301 on staging?
- Does a saved canonical PDF take the slug filename from the URL?

## Scope

- One shared filename derivation from the existing entry id.
- Move that name through the layout, builder, three HTML consumers, validator, and non-paper leak checks.
- Write `dist/_redirects` from `discoverPapers()` after the PDFs exist and before `validate:pdfs`. One explicit 301 per paper. Do not hand-write a second identity list. Do not use an unproven dynamic placeholder.
- Validator: canonical file present, physical `paper.pdf` absent, three consumers match, redirect lines complete, existing size/parse/citation/reference/relation checks kept, essays and IWLs still PDF-absent and free of paper-only metadata.
- Local `build` → `build:pdfs` → `validate:pdfs`, then push `staging` only. Verify every paper on the staging host.
- Update present-tense docs this rename makes false. `CHANGELOG.md` gets one entry. `ROADMAP.md` stays a current-state pointer.

## Explicit exclusions

No T18.2. No `main` promotion. No Article HTML URL change. No title-based filename. No second physical `paper.pdf`. No ORCID, IWL-link print, typography, pagination, table, or housekeeping fix. No edit of the closed T18.0 record. No indexing change.

## Implementation contract

- `paperPdfFilename(id)` returns `${id}.pdf`. Paths are `canonicalPath()` plus that filename, or the layout's existing canonical URL plus that filename. Both use the same id.
- Redirect source is `{route}paper.pdf`. Destination is `{route}{id}.pdf`. Status 301. The route string already comes from `canonicalPath()`.
- A dynamic Cloudflare placeholder is not used. It was not proven.
- Rollback: if staging does not 301 as specified, stop. Do not promote. Recovery is a revert commit on `staging` that restores `paper.pdf` emission and removes the redirect file, then a staging deploy of that revert. Do not invent a second architecture.

## Acceptance criteria

1. Each paper's canonical PDF URL returns 200 and PDF bytes. The file's URL ends in `{entry.id}.pdf`. No `Content-Disposition` renames it back to `paper.pdf`.
2. Each legacy URL returns an unfollowed 301 whose `Location` path is that paper's canonical PDF. No physical `paper.pdf` is in `dist`.
3. Highwire `citation_pdf_url`, JSON-LD `contentUrl`, and the Download href are the canonical URL. The Article canonical URL is unchanged.
4. The essay and the IWL have no PDF and no paper-only metadata. `noindex` and `Disallow: /` stay in force.
5. `validate:pdfs` fails closed on a missing canonical file, a physical legacy copy, or a wrong redirect line.

## Validation matrix

| Layer | Check | Expected result |
|---|---|---|
| Local | `npm run build`, `build:pdfs`, `validate:pdfs` | Green. `dist/_redirects` has four 301 lines. No `paper.pdf` file |
| Mutation | Plant a `paper.pdf` or drop a redirect line, rerun the validator, restore | Validator fails, then passes again |
| Staging | Unfollowed GET/HEAD for all four papers, essay, IWL | 200 / 301 / absence as specified |
| Indexing | `robots.txt` and a page's robots meta | Still `Disallow: /` and noindex |

## Adversarial tests

- A physical `paper.pdf` left beside the new file must fail validation.
- A redirect file missing one paper must fail validation.
- The Article canonical path must still end in `{entry.id}/`, not `{entry.id}.pdf`.
