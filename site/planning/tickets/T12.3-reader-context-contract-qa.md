## Goal

Validate Reader Context as one complete end-to-end research-object contract:

```text
AUTHORED SOURCE
readerNote
├── why
└── for
     │
     ├──────────────────────────────┐
     │                              │
     ▼                              ▼
HUMAN PROJECTION              MACHINE PROJECTION
FromTheAuthor                 Article.audience
├── why                       └── Audience
└── for                           └── audienceType = for

readerNote.why
└─────────────────────────────X→ no Schema.org projection

PDF
└─────────────────────────────X→ Reader Context absent
```

T12.3 does **not** add another Reader Context capability.

Its job is to prove that the source model, human surface, semantic surface, responsive shell, accessibility structure, absence behavior, and PDF boundary agree with one another after T12.0–T12.2.

---

## Why now

T12.0–T12.2 established Reader Context incrementally:

```text
T12.0
→ corpus audit
→ optionality and grammar earned

T12.1
→ source model
→ human surface

T12.1.1
→ mobile regression verification
→ visual polish

T12.2
→ readerNote.for → Article.audience
→ readerNote.why remains human-only
→ independent semantic validator
```

Each slice has been independently verified.

What has not yet happened is one deliberate QA pass that treats the complete system as a single contract before production promotion.

T12.4 must not become the place where cross-layer inconsistencies are first discovered.

## Starting state

Verified at validation base `a8c2867`:

* Four research objects exist: three papers and one essay.
* Invariants and Three SOS carry complete `readerNote` objects.
* FAFSA and Frontier carry no `readerNote`.
* `readerNote` remains optional at the module level and strict/complete-or-absent when present.
* `FromTheAuthor.astro` renders `why` and `for` only when `readerNote` exists.
* `FromTheAuthor` is an `<aside aria-labelledby="from-the-author-label">` with a non-heading label and no interactive controls.
* Reader Context is excluded from PDFs.
* `readerNote.for` emits:

  ```json
  {
    "@type": "Audience",
    "audienceType": "<authored readerNote.for>"
  }
  ```
* `readerNote.why` emits no machine projection.
* `Article.backstory` remains forbidden everywhere.
* The semantic validator independently derives expected audience state from source `readerNote`.
* All Sprint 12 work remains staging-only.
* `main` remains the production Sprint 11 baseline.
