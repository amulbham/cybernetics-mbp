Page hashes are expected, not proven, to return to the recorded state (the check reports a mismatch and does not force one); all six PDFs are re-typeset, so the Cognition PDF, equal to the approved bytes today, would also change. The Paper C deployment URL stays public until deleted. Nothing in Git, workflows, variables or production changes in this ticket.
