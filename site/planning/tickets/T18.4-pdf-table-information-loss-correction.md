## Goal

Eliminate the repeated PDF table information-loss defect T18.3 established, using the smallest reusable print-only correction that works across the paper corpus. The defect is proven; the remedy is a hypothesis to be tested, not a prescription.

## Why now

T18.3 found four paper tables clipped at the print column edge, with the clipped glyphs absent from the PDF text layer: F01 and F08 (FAFSA 5-column protocol tables), C01 (Chisel "The Other Workflow", third column), F06 (FAFSA §4.1, third header). T18.3 earned a bounded implementation experiment; this is it.

## Starting state

- Screen table mechanism: `.table-container` (`overflow-x: auto`, `tabindex="0"`), `thead th { white-space: nowrap }`, both in `global.css`; `print-research.css` has no table rule. The builder passes `print-research.css` to Vivliostyle as the PDF-only stylesheet, and that file already documents that `!important` is required to win over the page's own CSS.
- Renderer in this repo: `@vivliostyle/cli` 11.2.0, core 2.45.0, Chrome for Testing 152.0.7977.54.
- Cause at rule level is inferred, not isolated. T18.3 did not test any remedy.

## Decisions already frozen

Screen table behavior was accepted by T18.3 and must not change. PDF identity, redirects, Highwire, JSON-LD, indexing, the T18.2 masthead and IWL-link print rules, and the local-timezone date difference (out of scope) are untouched.

## Questions this ticket may answer

- Does a reusable print-only rule in `print-research.css` restore complete table content without a material legibility or pagination regression anywhere in the 19 paper tables?

## Implementation contract

- Prefer a general rule; reflow is allowed and expected where restoring content changes cell wrapping, row or table height, page breaks, page count, or table positions. Record each such change. Reject material regressions; do not require page counts or positions to stay fixed.
- Existing pagination observations (split rows, page-foot starts, stranded heading) are not automatically defects and are not authorized fixes.
- A rule that only fixes the four named cases, or needs content, author intent, or new syntax, fails the ticket.
- Absence of any print-side regression is judged on rendered pages, not on text extraction.
