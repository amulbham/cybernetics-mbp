## Acceptance criteria

1. The contract states the unconditional noninterference rule, including zero primitive inputs and user-approved citations/emphasis.
2. A clean `assets/manuscript.md` plus optional handoff **and** a one-MD combined package both map to clean site output without claiming the latter is already automated.
3. Combined-file malformed-boundary behavior is fail-closed as *specified*, and the actual extractor/validator implementation is clearly marked unimplemented.
4. Exact existing schema fields, optional abstract behavior, route/PDF distinction, absent/pending metadata and the three approval states match source truth.
5. Source Markdown grammar and anchors defer to CONTENT-MODULES; invalid empty bodies, labels and IDs are review errors; no arbitrary primitive quota.
6. Citation/reference policy preserves existing authorial mode, with the Lab Bubble 23-numbered-link exception bounded to the approved piece and verified in actual HTML only later.
7. The content-manager skill's old add-primitives-on-upload instruction is eliminated or explicitly superseded; no stale “full abstract required”/deindexed/built-in new-paper guarantee remains.
8. Planned nonpublishing fixtures cover a zero-primitive source, malformed input, combined boundary, no-abstract pending metadata, FAFSA v2.4, Chisel and Lab Bubble. Distinguish **reviewed static evidence** from **not-run build/handoff tests**.
9. Changes are docs-only on `planner/context`, with no deployment or unauthorized branch integration, and an attributable completion report under ticket/report line caps.
