## Implementation contract
- **Hostname coverage.** Test the branch alias and **every immutable preview URL** the project ever serves under this ticket (canary 1 until deleted, canary 2, the candidate), the production hostname `cybernetics-mbp-preview.pages.dev`, and the existing live hosts. A deployment in `wrangler pages deployment list` not accounted for stops the run. Custom domains and aliases must be none.
- **Anonymous denial (`anonymous-denial-check.mjs`).** No cookies or custom headers; article GET and HEAD, PDF GET, HEAD and `Range: bytes=0-15`, on the alias and on each immutable URL. Judge the **first** response only; redirects are not followed implicitly. Pass: a 301/302/303/307/308 whose `Location` is `https` on `*.cloudflareaccess.com` with path `/cdn-cgi/access/…`, or a 401/403, with no PDF content type, no `Content-Range`, no `%PDF-` bytes and no candidate marker. Then **validate the Access login redirect separately** (one request to the `Location`: an Access login page, or a further redirect inside the Access host, with no artifact bytes). Any 200, 206, 304 or 404 first response on a protected host fails. On the production hostname and live hosts the article and PDF must be 404 with no artifact.
- **Negative controls.** Before any verdict, `https://amulbham.com/` (public HTML) and `https://amulbham.com/research/cybernetics/three-self-organizing-systems/three-self-organizing-systems.pdf` (public PDF, with and without Range) must each be judged EXPOSED. If not, the check is untrustworthy and the phase stops.
- **`_headers`.** It stays hashed in the local inventory and digest; it is excluded from hosted download comparison (Pages applies it and does not serve it); its effect is verified on hosted responses: every authenticated response carries `X-Robots-Tag: noindex, nofollow` exactly (Cloudflare's own default is `noindex`).
- **Authenticated verification (owner-run, owner-supplied evidence).** The Access session cookie lives only in an environment variable on the owner's machine and is never sent to the Executor. The kit downloads every inventory file from the **immutable** origin except `_headers`; all seven PDFs (the six historical pairs by path and hash plus the candidate PDF `fe6eaf21…9446`) and every non-HTML file are compared byte-exact; HTML files are informational; the article page must carry the noindex meta, `Candidate specimen` and `Download candidate PDF` and no canonical, JSON-LD or `citation_` tag; the seven PDFs are repeated on the alias. A hand fallback (browser save plus `Get-FileHash` against the pinned table) is allowed.
- **Captures (owner, immutable URL only).** Ordered desktop (1440 px) and mobile (390 px) viewport or full-page images, `desktop-NNN.png` / `mobile-NNN.png`, with `page-metrics-*.json` copied from the page. The kit rejects a numbering gap, a wrong width, total height below the page height, a non-PNG file, or a metrics URL other than the immutable article URL, and writes `capture-index.json` binding each image hash to the immutable URL, candidate PDF hash, upload digest, correction commit and the hash of the verification report.
- **Failure and containment.** Any denial miss, digest or hash mismatch, unexpected hostname or deployment, or Access misconfiguration stops the run. After a candidate upload: upload a neutral deployment to the same label, delete the candidate deployment with `wrangler pages deployment delete <id> --project-name cybernetics-mbp-preview --force` (the latest deployment of a branch cannot be deleted), verify, and return. No retry without a new GO.
