## Implementation contract
- **Hostname and path coverage.** The branch alias and **every immutable preview URL** the project serves under this ticket (canary 1 until deleted, canary 2, the candidate), the production hostname, and the existing live hosts. On each protected origin: article GET and HEAD; PDF GET, HEAD and `Range: bytes=0-15`; root; explicit `index.html`; the article without a trailing slash; the article with a query string; `robots.txt`; `sitemap-index.xml`; one `/_astro/*` asset. A deployment in `wrangler pages deployment list` not accounted for stops the run; custom domains and aliases must be none.
- **Anonymous denial (`anonymous-denial-check.mjs`).** No cookies or custom headers. Judge the **first** response only; redirects are not followed implicitly. Pass **only** for a 301/302/303/307/308 whose `Location` is `https` on the owner's Access team host with path `/cdn-cgi/access/…` and no PDF type, no `Content-Range`, no `%PDF-` bytes and no candidate marker (case-insensitive). A bare 401/403 is not attributable to Access and fails unless the owner explicitly allows it. **Validate the Access login redirect separately** with one more request. Any 200, 206, 304 or 404 first response on a protected host fails. The production hostname and live hosts must be 404 with no artifact. The response `server` and `cf-ray` headers are recorded.
- **Negative controls.** Before any verdict, `https://amulbham.com/` (public HTML) and `https://amulbham.com/research/cybernetics/three-self-organizing-systems/three-self-organizing-systems.pdf` (public PDF, GET, which must return `%PDF-` bytes, and Range) must each be judged EXPOSED; otherwise the phase stops.
- **`_headers`.** Hashed in the local inventory and digest; excluded from hosted downloads (Pages applies it and does not serve it); its effect is verified: every authenticated response carries `X-Robots-Tag: noindex, nofollow` exactly (Cloudflare's own default is `noindex`).
- **Authenticated verification (owner-run, owner-supplied evidence).** The app-host Access cookie lives only in an environment variable typed at a prompt, with shell history off, and is removed afterwards; it is never sent to the Executor. The kit downloads every inventory file from the **immutable** origin except `_headers` (HTML pages other than `index.html` are requested at their extension-less URL, because Pages redirects `.html`). All seven PDFs (six historical pairs by path and hash plus the candidate `fe6eaf21…9446`) and every non-HTML file are compared **byte-exact**; the **article page must equal `3b9e3169…b743` byte-exact** (other HTML pages are compared informationally and counted; a host rewrite of the article page stops the run for a reviewed exception); the article markers are checked; the seven PDFs are repeated on the alias with its own cookie if needed.
- **Captures (owner, immutable URL only).** `desktop-NNN.png` at 1440 px and `mobile-NNN.png` at 390 px (±2), with `page-metrics-*.json` from the console snippet in the kit README, which also fetches the page and records its SHA-256. The index step refuses: an origin that is not `https://<8 hex>.cybernetics-mbp-preview.pages.dev`; a metrics URL not exactly the immutable article URL; a browser-fetched HTML hash other than the pinned one; a numbering gap; invalid, duplicate or tiny PNGs; total height below the page height; and a missing, failed or other-origin report. It records the observed candidate hash and report hash. **The index is owner-attested.**
- **Failure and containment.** Any denial miss, digest or hash mismatch, unexpected hostname or deployment, subdomain mismatch, or Access misconfiguration stops the run. Fastest containment: **delete the whole project** (removes every hostname), verify every hostname is gone, return. The slower neutral-deployment-then-delete path (the latest deployment of a branch cannot be deleted) is only for non-exposure issues. No retry without a new GO.
