## Implementation contract

- The burden of proof is on structure. A `STRUCTURE EARNED` row needs a present, accepted operation and a demonstrated residual failure after testing prose/convention and existing safeguards. Recurrence, intellectual importance, a hypothetical query, or future CMS/graph convenience is insufficient.
- A missing draft cannot be reconstructed or encoded as verified history. `UNDECIDABLE` applies to the claim's evidentiary basis; it does not by itself require a new schema for uncertainty.
- If an existing outer field already prevents the failure, mark it solved. If no inner fact passes, recommend OPAQUE V1 for currently accepted MVP operations, with a concrete revisit trigger.
- H stays outside every Git worktree; Git receives only a bounded, non-reconstructive report. Source outputs A–G remain unchanged.
