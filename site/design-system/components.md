# Components

The existing set only — this is a record of what's real, not a catalog of what's possible. Adding a new component when a token plus an existing one will do is out of scope (see `do-not.md`).

- **Button** (`Button.astro`) — `primary`: `background: var(--accent)`, `color: var(--accent-fg)`, no box-shadow. `secondary`: `1px solid var(--border)`, `color: var(--text-primary)`, transparent fill. `ghost`: no border/fill, `color: var(--accent)`.
- **Card** (`Card.astro`) — `background: var(--bg-raised)`, `1px solid var(--border)`, `--radius-lg`. Hover: border → `--accent`. A baseline `--shadow-sm` (real in light mode, `none` in dark, so no explicit dark-mode override needed). No full-card pillar tint, ever — a 3px pillar-colored leading edge is allowed on research cards specifically, not shipped by default.
- **Badge** (`Badge.astro`) — pill shape, a small dot, a label. Category ("pillar") variant: 12% wash background + a 20%-opacity border in the same category color, text in the category color; shown on every research card with the entry's editorial category (T19.0). Neutral variant (generic tags): `--bg-subtle` background, `--text-secondary` text, no dot.
- **Header** (`Header.astro`) — `background: var(--bg)`, `1px solid var(--border)` bottom hairline. Active nav link: `2px solid var(--accent)` underline (not 4px — Signal-pass change). Contains the skip link (`.skip-link`, visually hidden until `:focus`, targets `#main-content`). Search is a utility control (`.search-control`, circular icon button matching `ThemeToggle`'s box exactly — same size, border, hover), not a text nav link — it lives in `.right-controls` next to the theme toggle, not `.internal-links`, and its active state is a full border ring (`aria-current="page"` → `border-color: var(--accent)`) rather than a text link's underline, since a circle can't take an underline without looking broken. Below 768px, `Home` and the brand wordmark (`.brand-text`) hide — Research/About/Search/theme stay full-size; the header stays one row at every width down to 375px (see `README.md`'s Responsive section, Sprint 6.1/6.5).
- **ThemeToggle** (`ThemeToggle.astro`) — icon swap (sun/moon) driven by the same `[data-theme]`/`prefers-color-scheme` pattern as every color token. `aria-pressed` updates on click (session-relative only — see the in-code comment for why it isn't synced on initial load).
- **Spotlight** (`Spotlight.astro`) — the homepage's one pinned editorial cell, above `RecentResearch`. Same object language as Recent (`Card`/`Badge`/`FormattedDate`), just one entry at full `--content-width-wide` instead of a 3-up grid — not a second card system, not a scaled-up grid cell. Labeled with a plain `.meta` line, `Spotlight` — no badge rainbow. Pinned via `HOMEPAGE_SPOTLIGHT` in `consts.ts` (Sprint 6.3); `RecentResearch` takes an `excludeId` prop so the pinned piece never doubles into the three-up below it.
- **Footer** (`Footer.astro`) — identity row + thin wayfinding, not a second sitemap (Sprint 6.2). First row: copyright + `SocialLinks` (unchanged). Second row (`.footer-nav`): two `.meta`-styled lines — site links (`Home · Research · About`) and the four categories (`CATEGORIES` in `src/lib/categories.ts`, never hardcoded; route-only memos is not listed), `·`-separated, links underline only on hover/focus, no boxes or dots. Mono, `text-xs`, `--text-secondary` throughout — quieter than the article it follows. `SocialLinks` now carries a fourth chip, ORCID (`iD`, text-only — same recipe as `in`/`S`/`</>`, no icon). ORCID is never redrawn or recolored; a text chip with no mark is the correct fallback, not a compromise.
- **ScrollProgress** (`ScrollProgress.astro`) — 2px bar (not 3px), `background: var(--accent)`, hidden entirely under `prefers-reduced-motion: reduce`.
- **TableOfContents** (`TableOfContents.astro`) — rail/mobile links in `--text-secondary`; active link is `--accent` + `font-weight: 700` + a 2px left accent border (not just a color change).
- **ArticleMasthead** (`ArticleMasthead.astro`) — name/affiliation/correspondence/format/license, rendered automatically from `AUTHOR`/`SOCIAL_LINKS` in `consts.ts` and the work's effective license (`src/lib/license.ts`). Not a color exception to anything here — it's `.meta`-styled text, same as any other metadata line.
- **Alerts / key-findings / pull-quote / tables / figures** — all build-time Markdown transforms, not components; see their classes directly in `global.css` (`.markdown-alert*`, `.key-findings*`, `.pull-quote`, `.table-container`, `figure`/`figcaption`). One shared surface language across all of them: a hairline border plus either a plain surface (`--bg-subtle` for the table header, and for key-findings in print; `--bg-raised` for key-findings on screen, see below) or a severity/pillar wash (alerts, badges) — never a third treatment. Pull-quote is large type, centered, deliberately **no** left rule (that's what distinguishes it from an ordinary citation blockquote, which keeps the left rule).
- **Research primitives** (`.research-primitive*`) — the five kinds (definition/key-idea/evidence/counterpoint/implication; contract in `CONTENT-MODULES.md`) share one structure: `1px solid var(--border)`, a **6px** left rule (deliberately heavier than a pull-quote's — pull-quote has none at all, alerts use 4px — so a primitive is visually its own thing, not mistaken for either), and a `.meta`-treatment mono, uppercase, **`font-weight: 700`** label (tuned 2026-08-26, Sprint 3.1). The label word is always the first signal; color is the second and is never relied on alone. No icons.
  - **Print and the non-screen baseline (unchanged, frozen PDFs):** one recipe for all five — `background: var(--bg-subtle)`, rule and label in `--accent`. `print-research.css` styles this baseline; the screen variants below are inside `@media screen` and do not reach it.
  - **Screen (T31.1):** each kind takes its own `--primitive-*` ink (see `tokens.md`) for the 6px rule and the label, plus a 1px label hairline at 28% of the label color. Definition, evidence, counterpoint and implication sit on an 8% wash of their ink over the page field. **Key idea** shares steel with Definition, so it is told apart by surface and size: `--bg-raised` instead of a wash, and body set to `1.15em` / `1.45` (still under a pull quote).
- **Key Findings** (`.key-findings`, from `rehype-key-findings.mjs`) — markup unchanged: `section.key-findings` > `h2#key-findings` + a native `ul` (an `ol` is accepted by the transform and takes the same styling). **Screen (T31.1):** a raised panel — `--bg-raised` with the existing plain 1px `--border` outline and **no** left bar (the bar belongs to the primitives), the heading set as a compact mono section label (`--text-xs`, 700, uppercase, `--accent`, hairline underneath), `--accent` list markers, and 1em between items. That is how it differs from a primitive (colored bar, in-body label), an alert (4px bar plus wash), a pull quote (centered large type, no frame) and a citation blockquote (plain left rule). **Print and the non-screen baseline (unchanged):** the shared `--bg-subtle` box with the `--text-lg` heading, styled by `print-research.css`.
- **Research reading rhythm** (T31.1, screen only) — on research articles only (recognised by the masthead the shared shell renders; the IWL companion and About reuse `.prose` and are untouched), direct-child section `h2`s get a `2.75em` top margin, a section rule `2.75em 0 1.35em`, and an `h2` directly after a rule has no top margin; at 720px and below those `h2`s use `--text-2xl`. Lab Bubble keeps its own T26.2 spacing and is excluded from the margin rules. Whole-bold paragraphs get no special size or margin (a standalone-bold selector also matches mixed-text paragraphs, so it was not shipped).
- **Homepage hero** (`index.astro`) — left-aligned (not centered — Signal-pass change). Eyebrow: mono font, `--accent`. Lede/supporting paragraph: `--text-secondary`. Exactly two CTAs (primary + secondary `Button`), never more.
- **Prose links** (`.prose a` in `global.css`) — underlined, `text-underline-offset: 0.15em`, `--accent` → `--accent-hover` on hover. No visited-purple; this project doesn't distinguish visited link state. `#ref-*` inline citations are the one exception: ink-colored with a dotted underline (`--border`, brightening to `--accent` on hover/focus) rather than solid `--accent` — they point on-page, not outbound (Sprint 6.4; see `CONTENT-MODULES.md`'s Citation links → Routing).
