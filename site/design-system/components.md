# Components

The existing set only — this is a record of what's real, not a catalog of what's possible. Adding a new component when a token plus an existing one will do is out of scope (see `do-not.md`).

- **Button** (`Button.astro`) — `primary`: `background: var(--accent)`, `color: var(--accent-fg)`, no box-shadow. `secondary`: `1px solid var(--border)`, `color: var(--text-primary)`, transparent fill. `ghost`: no border/fill, `color: var(--accent)`.
- **Card** (`Card.astro`) — `background: var(--bg-raised)`, `1px solid var(--border)`, `--radius-lg`. Hover: border → `--accent`. A baseline `--shadow-sm` (real in light mode, `none` in dark, so no explicit dark-mode override needed). No full-card pillar tint, ever — a 3px pillar-colored leading edge is allowed on research cards specifically, not shipped by default.
- **Badge** (`Badge.astro`) — pill shape, a small dot, a label. Pillar variant: 12% wash background + a 20%-opacity border in the same pillar color, text in the pillar color. Neutral variant (used for Essay/Memo format labels, and generic tags): `--bg-subtle` background, `--text-secondary` text, no dot.
- **Header** (`Header.astro`) — `background: var(--bg)`, `1px solid var(--border)` bottom hairline. Active nav link: `2px solid var(--accent)` underline (not 4px — Signal-pass change). Contains the skip link (`.skip-link`, visually hidden until `:focus`, targets `#main-content`). Search is a utility control (`.search-control`, circular icon button matching `ThemeToggle`'s box exactly — same size, border, hover), not a text nav link — it lives in `.right-controls` next to the theme toggle, not `.internal-links`, and its active state is a full border ring (`aria-current="page"` → `border-color: var(--accent)`) rather than a text link's underline, since a circle can't take an underline without looking broken. Below 768px, `Home` and the brand wordmark (`.brand-text`) hide — Research/About/Search/theme stay full-size; the header stays one row at every width down to 375px (see `README.md`'s Responsive section, Sprint 6.1/6.5).
- **ThemeToggle** (`ThemeToggle.astro`) — icon swap (sun/moon) driven by the same `[data-theme]`/`prefers-color-scheme` pattern as every color token. `aria-pressed` updates on click (session-relative only — see the in-code comment for why it isn't synced on initial load).
- **Footer** (`Footer.astro`) — identity row + thin wayfinding, not a second sitemap (Sprint 6.2). First row: copyright + `SocialLinks` (unchanged). Second row (`.footer-nav`): two `.meta`-styled lines — site links (`Home · Research · About`) and all 5 pillars (`Object.keys(PILLAR_DESCRIPTIONS)`, never hardcoded), `·`-separated, links underline only on hover/focus, no boxes or dots. Mono, `text-xs`, `--text-secondary` throughout — quieter than the article it follows. `SocialLinks` now carries a fourth chip, ORCID (`iD`, text-only — same recipe as `in`/`S`/`</>`, no icon). ORCID is never redrawn or recolored; a text chip with no mark is the correct fallback, not a compromise.
- **ScrollProgress** (`ScrollProgress.astro`) — 2px bar (not 3px), `background: var(--accent)`, hidden entirely under `prefers-reduced-motion: reduce`.
- **TableOfContents** (`TableOfContents.astro`) — rail/mobile links in `--text-secondary`; active link is `--accent` + `font-weight: 700` + a 2px left accent border (not just a color change).
- **ArticleMasthead** (`ArticleMasthead.astro`) — name/affiliation/correspondence/format/license, rendered automatically from `AUTHOR`/`LICENSE`/`SOCIAL_LINKS` in `consts.ts`. Not a color exception to anything here — it's `.meta`-styled text, same as any other metadata line.
- **Alerts / key-findings / pull-quote / tables / figures** — all build-time Markdown transforms, not components; see their classes directly in `global.css` (`.markdown-alert*`, `.key-findings*`, `.pull-quote`, `.table-container`, `figure`/`figcaption`). One shared surface language across all of them: a hairline border plus either `--bg-subtle` (key-findings, table header) or a severity/pillar wash (alerts, badges) — never a third treatment. Pull-quote is large type, centered, deliberately **no** left rule (that's what distinguishes it from an ordinary citation blockquote, which keeps the left rule).
- **Research primitives** (`.research-primitive*`) — the five kinds (definition/key-idea/evidence/counterpoint/implication; contract in `CONTENT-MODULES.md`) all share one recipe, label-only distinction: `background: var(--bg-subtle)`, `1px solid var(--border)`, a **6px** left rule in `--accent` (deliberately heavier than a pull-quote's — pull-quote has none at all, alerts use 4px — so a primitive is visually its own thing, not mistaken for either). Label is `.meta`-treatment mono, uppercase, **`font-weight: 700`** (tuned 2026-08-26, Sprint 3.1 — the original weight-inherited label didn't read as a label against `--bg-raised`, which was also too close to the page's own `--bg` to register as a distinct field; both fixed together). No per-kind fill colors, no icons — the label word is the only thing that distinguishes the five.
- **Homepage hero** (`index.astro`) — left-aligned (not centered — Signal-pass change). Eyebrow: mono font, `--accent`. Lede/supporting paragraph: `--text-secondary`. Exactly two CTAs (primary + secondary `Button`), never more.
- **Prose links** (`.prose a` in `global.css`) — underlined, `text-underline-offset: 0.15em`, `--accent` → `--accent-hover` on hover. No visited-purple; this project doesn't distinguish visited link state. `#ref-*` inline citations are the one exception: ink-colored with a dotted underline (`--border`, brightening to `--accent` on hover/focus) rather than solid `--accent` — they point on-page, not outbound (Sprint 6.4; see `CONTENT-MODULES.md`'s Citation links → Routing).
